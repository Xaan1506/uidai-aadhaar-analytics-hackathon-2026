# Data directory

WARNING: RAW UIDAI DATASETS ARE NOT INCLUDED IN THIS REPOSITORY.

To reproduce the analysis using official datasets, download the required aggregated UIDAI datasets from the official hackathon portal and place them in data/raw/ (this path is git-ignored).

For development and testing, use the anonymized sample files in data/sample/ (100 rows each). Contextual public data is in data/public/.
